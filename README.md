**MSc Mechatronics Engineer · Machine Vision, Embedded AI & Robotics**

I build AI and machine vision systems for production lines and take them end to end: camera and optics selection, model training, real-time inference on embedded NVIDIA hardware, robot and PLC integration, and on-site commissioning.
